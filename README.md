# The Aether

A Fabric mod for **Minecraft Java Edition 26.2** that adds a new sky dimension.

## Development setup

- Minecraft: 26.2
- Java: 25
- Fabric Loader: 0.19.3
- Fabric Loom: 1.17
- Gradle: 9.5.1
- Fabric API: 0.161.0+26.2

Install JDK 25 and use IntelliJ IDEA or VS Code. The GitHub Actions workflow builds the mod with Gradle.

## Build

Run the Gradle `build` task. The distributable mod JAR will be created in `build/libs/`.

## Project status

This is the initial project foundation. The Aether dimension, portal, biomes, blocks, items, and creatures will be implemented in upcoming commits.
